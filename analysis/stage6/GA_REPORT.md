- **L = 450 권고(주 그림)**: 세 정책 모두 pre 가 건강하고(10.8~19.8 ms),
  `corrected ≈ service`(백로그 없음)라 **한 개의 선형 y축**에 다 들어간다.
  SLO 45 ms 선이 정책을 가른다(both p95: SORTS 43.8 < 45 < lr 53.2).
  "밴드 하락 → 엣지 이동 → SLO 유지"가 한 장에서 읽힌다.
- **L = 800 보조**: 4단계 누적표 앵커 지점이지만 `bl_loc_pri` 가 **교란 전
  부터 이미 포화**(pre svc p50 86.8 ms)이고 corrected 가 **65 초**(생성기
  스케줄 백로그)라 같은 축에 못 올린다. 로그 y축 + "loc_pri 는 pre 부터
  포화" 주석이 필요하다. 앵커 표시용으로 별도 산출 권고.
