## 판정 (사전 등록 기준) — **보류**

1. 평균 차 > 반범위 합: |0.149−30.34|=30.2 < 35.4 (strict 쌍봉이 반범위를
   폭파) → **불충족**.
2. 기전이 전 strict 런에서 일관: 3/7 만 락인 → **불충족** (락인한 런에서는
   3/3 동일 기전).
3. 커넥션 분해: 락인 런은 비중첩(min 69.9 vs far max 0.29), 미락인 런은
   무차이 → **부분 충족**.

**셋 다 만족 못 하므로 승격하지 않는다.** 단, 기준 1·2는 현상이 단봉이라는
암묵 가정 위에 등록된 것이고 실제 현상은 쌍봉이다 — 기준이 틀린 게 아니라
**주장을 바꿔야 한다**: "strict 는 항상 붕괴한다"(기각됨)가 아니라
"**strict 는 클린 고부하에서 준안정 진동 어트랙터를 노출하고(락인 시 70 %
위반), far_tier 는 어트랙터 자체를 제거한다**"가 올바른 주장이다.

발생률 검정: strict 3/7 vs far 0/4 — Fisher 정확 p≈0.24 (야간 포함 4/8 vs
0/5, p≈0.10). **현 n 으로는 발생률 차이의 유의성이 없다.**

## 필요한 추가 실험 (제안)

1. **트리거 통제 실험 (권장)**: 락인 여부만 확률적이므로, 초기 요동을
   결정적으로 주입(예: 기동 직후 1~2 tick 동안 S3 에 인위 부하 스파이크
   또는 관측 창 오염)하고 두 정책의 **락인 여부**를 비교하면 발생률 표본
   문제가 사라진다 — "같은 트리거에 strict 는 고착, far 는 복귀"가 목표
   주장. 런당 6분짜리로 n=5/arm 이면 충분할 것.
2. 발생률 경로를 고집한다면 strict n≥15 필요 (p<0.05 위해).
3. stale_ttl 민감도는 **파라미터 튜닝 금지 규칙과 별개의 후속 설계 결정** —
   락인의 유지 기전이 stale_ttl 임이 규명됐으므로, 작업 B(용량 제약)가
   이 사이클을 원천 차단하는지가 1차 검증 항목이 되면 충분하다.
