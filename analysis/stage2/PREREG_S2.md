# STAGE2 사전 등록 (G1 회신 반영판, 2026-08-11 — 본 배치 기동 전 확정)

원 등록(STAGE2 지시 §2)은 전부 유효. 아래는 G1 회신으로 **본 배치 결과를
보기 전에** 추가·구체화된 항목이다.

## 1. 첫 전환 시각 — 두 기준 분리 (모든 보고에 기준 명시)

- **t_issue 기준** = c1:search 첫 `changed` tick(.43) − (`radio_on.t_issue`
  + d43). ssh 램프(~0.86 s) 포함. **P-S2-0 앵커 판정은 이 기준**,
  대역 1.08~1.14 s (2자리 반올림 비교), 원 등록 유지.
- **t43_done 기준** = 동일 tick − `radio_on.t43_done` (적용 완료).
  **P-S2-1 예측(50 ms < 0.2 s, 25 ms < 0.15 s)은 이 기준.** T=1 s 재현대
  0.22~0.28 s (phase4 A1~A4 원자료 재계산).
- ssh 램프 실측치(apply_lat_s)는 앵커런·본 배치 보고에 병기 — t_issue
  기준 이탈의 코드/램프 귀속 분리용.

## 2. 주 지표 ① (G1 §2.2 승인)

during(120~240 s) 위반율을 (a) 전체(코호트 가중 Σn·rate/Σn)와 (b) **c1
search** 로 병기, **채택 규칙(P-S2-2: 겹치면 느린 주기) 판정은 (b)**.
근거: radio config 에 both 창 부재; (a)는 밴드로 못 지키는 라우팅 무관
성분(c1 recommend/reserve ~6.3-6.4 %)이 지배해 T 효과 불가시; (b)가
phase4 §6 표·표4·P-S2-1 과 동일 모집단. 결과를 보기 전 변경.

## 3. 진동 가드레일 (G1 §3 — 원 등록 유지 + 보조 등록)

- 원 등록(절대 20회/런 초과 시 채택 보류)은 **삭제하지 않는다**. 전 arm
  발동이 예상되며(미니 런 사전 신호 13회/20 s), 발동 사실을 그대로 보고.
- **보조 가드레일(신규)**: 채택 후보 arm 의 c1:search 전환 횟수가 T=1 s
  arm 대비 **1.5배 초과 증가** 시 채택 보류·보고. 원 의도("빠른 주기가
  진동을 새로 만드는가")의 재표현 — baseline 에 이미 있는 진동은 T 가
  만든 것이 아니다. **본 배치 결과를 보기 전, 미니 런 n=1 관측 후 변경**
  (method_cases.md B-3).

## 4. P-S2-3 (신규 등록): S2↔S1 플립 왕복 주기는 T 비의존

예측: 전 arm 에서 c1:search 왕복 주기 p50 ∈ **1.8~2.2 s** (WINDOW_S 2.0
귀속 가설). T 에 비례해 짧아지면 가설 기각 → 기전 재특정 (정지 아님 —
보고 대상). 진단 표: arm별 c1:search 전환 횟수 / 왕복 주기 p50 / S2 slack
0-교차 횟수. 기전 서술은 config 등가성 확인(§5) 전까지 "같은 결함(결정이
자기 부하 효과를 모름)의 radio 축 4차 발현" **잠정** 귀속 — "코드 개정의
신규 발현" 확정 서술 금지. 이번 범위에서 결정 로직 수정 없음(완화안은
3단계 이후 별건).

## 5. 앵커런 (G1 §2.1 (b) 승인, 조건 3)

- 본 배치와 **완전 동일 조건** 1런 (T=1 s, warmup 60, duration 360,
  radio 120~240, 800 rps — 미니 런 단축 금지).
- ssh 램프 실측 + 두 기준 병기 보고.
- **config 등가성 대조표**: phase4 A2/A4 arm ↔ 앵커런 arm (radio 축 관련
  전 플래그) — 차이가 있으면 §7-2 귀속("코드 개정 신규 발현") 재검토.
- 판정: t_issue 기준 재현(1.08~1.14) → **본 배치 즉시 기동(승인 불필요)**.
  이탈 → 정지·보고. 대역 재정의 없음.

# [v3 primitive 개정판] 2026-08-12 — 본 배치 데이터 이전 등록

§4 회신 승인으로 주입 primitive 를 v3(배치+재배열)로 교체했다
(`V3_PRIMITIVE_REPORT.md`). 아래는 **새 primitive 위에서의 재등록**이며,
전부 **본 배치 착수 전·데이터 없음** 상태에서 기록한다. 원 등록(§1~§5)은
삭제하지 않는다.

## 6. 실측 시각 분해 (재등록의 근거, v3 검증 런)

| 구간 | 값 | 성격 |
|---|---|---|
| 지시 → 가시화 = 발효 (A1=F1) | **0.256 s** | ssh+sudo+bash 시동 + tc 배치(~10 ms) |
| 발효 → 감지 tick | **[0, T)** | tick 위상이 결정. 런 config 고정 시 거의 상수 |
| 감지 → apply 완료 | ~0.7 ms | `apply_latency_ms` |

**flush(corr p50 52.6 ms)는 이 경로에 없다.** `read_rates()` 는 tick 마다
`tc qdisc show` 를 **직접** 호출하며 Envoy 액세스 로그를 거치지 않는다(코드
경로). 실측 방증: 구·신 계열 **8런 전부에서 "감지 tick == observed_rate 가
처음 비지 않은 tick"** 이다. flush 는 `obs.py` 의 f_c·바이트 관측에만 관여해
결정의 *내용*(slack 값)에 영향을 주며, radio 축은 d_acc 점프(17.118 ms)가
지배해 같은 tick 에 전환이 성립한다. — 지시 §5 의 "발효 + T + flush" 유도에서
flush 항을 뺀 이유이며, 이 판단 자체를 등록해 사후 변경을 막는다.

## 7. P-S2-1 재등록 (구 등록 "T=50 ms 에서 0.2 s 미만" 폐기 — 구 primitive 의
`T_v`=0.26 s 를 전제한 수치였다)

기준점은 **물리적 발효(A1=F1)** 로 바꾼다. 이하 "지연" = 발효 → 첫 전환 완료.

- **P-S2-1a (하드 상한, 주 검정)**: 전 런에서 지연 < **T + 10 ms**.
  (T=1 s → <1.01 s / 50 ms → <60 ms / 25 ms → <35 ms)
- **P-S2-1b (기대값)**: 위상이 균등하면 E[지연] = T/2. 단 위상은 런 config
  에 대해 **결정적**이므로 n=3 안에서는 거의 상수일 수 있다 — 평균이 T/2 와
  달라도 기각 사유 아님(상한 a 만 검정 대상).
- **P-S2-1c (burst 위반)**: burst 위반 ≈ 지연 × c1 search 도착률(≈133 req/s).
  상한 기준 T=1 s 133건 / 50 ms 6.7건 / 25 ms 3.3건 →
  **T=50 ms 는 T=1 s 대비 ≥80 % 감소, T=25 ms 는 ≥90 % 감소**.
- **P-S2-1d (주 지표 파급 — 채택 규칙의 사전 예고)**: during 창 120 s 의
  c1 search 는 약 16,000건이고 burst 구간은 최대 133건(**0.83 %**)이므로,
  **arm 간 during(c1 search) 위반율 차이는 ~1 %p 이하**로 예상된다. 즉
  P-S2-2 의 "구간이 겹치면 더 느린 주기 채택" 규칙상 **1 s 채택이 유력한
  결론**이며, 이는 예측 실패가 아니라 결과다(§4 회신 §5 취지와 동일).

## 8. 신규 앵커 (P-S2-0' — v3 primitive 기준, T=1 s n=3 실측으로 확정)

원 P-S2-0(1.08~1.14 s, t_issue 기준)은 **구 primitive 전용**이며 tick 양자화
+ 경계 인접으로 회귀 앵커 부적격임이 규명됐다(보존·미삭제). 대체 앵커는
**위상 의존 항과 무관한 두 축**으로 구성한다:

- **(a) primitive 앵커** — A1(지시 → 가시화 = 발효). T=1 s n=3 실측
  평균 ± max(3σ, 30 ms) 를 대역으로 등록. 주입 경로(ssh·sudo·배치)의 회귀를
  잡는다. *위상 무관.*
- **(b) 결정 내용 앵커** — 감지 tick 에서 `observed_rate` = 2300,
  `d_acc` = **17.118 ms**, 전환 = c1:search → **S2**, `feasible_set` = {S2}.
  이 네 값은 **phase4(구 계열)와 b3(신 계열)에서 이미 동일하게 재현**됐다.
  *위상·primitive 무관* — 결정 로직의 진짜 회귀 앵커.
- **(c) 반응 상한** — 첫 전환 지연(발효 기준) < T + 10 ms (= P-S2-1a).
  위상 의존 값 자체는 앵커로 쓰지 않는다.

이탈 시 처리: (b) 이탈 = 결정 로직 회귀 → 즉시 정지. (a) 이탈 = 주입 경로
변화 → 정지·보고. (c) 이탈 = 루프/스케줄 이상 → 정지·보고.
