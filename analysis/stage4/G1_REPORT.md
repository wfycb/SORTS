## 1. §2.1 감쇠 주입 지점 — 미러 인터페이스 방식 (프로토타입 검증 완료)

### 1.1 구조

`read_rates(cfg["iface"])` 는 **iface 가 이미 config 주도**다(sorts_ctl:504).
shim 데몬(`analysis/stage4/obs_shim.py`)이 소스(ogstun)의 netem 상태를
읽어(컨트롤러와 동일 정규식) 감쇠 변환 후 **미러 더미 인터페이스
(obsshim0)** 에 코호트당 leaf 1개로 재게시한다. 컨트롤러는 iface 만
obsshim0 으로 바꾸면 감쇠 관측을 받는다:

- `sorts_ctl.py`·`obs.py` **무수정** — read_rates 는 원래 하던 일을 그대로
  한다. 결정 로직 무접촉, **입력값만** 변형(§2.1-2 충족).
- 실제 셰이핑(ogstun)은 그대로 — 관측 채널만 감쇠된다.
- 미러는 트래픽 없는 더미라 데이터패스 무영향.

### 1.3 ★동결 접촉 1건 — 해제 판단 요청

미러 이름을 컨트롤러에 전달하는 유일한 경로가 렌더 체인이다:

| 파일 | 필요한 수정 | 규모 |
|---|---|---|
| `sorts.yaml.tmpl` (동결) | `iface: ogstun` → `iface: %OBS_IFACE%` | 토큰 1개 |
| `run_all.py` (동결) | 렌더 치환 1곳 + run 스펙 `obs_iface`(기본 **"ogstun"** = 종전 거동) + 유효값 재검증 | ~6줄 |

`ctl_period_s` 파라미터화(1단계 해제)와 동형의 최소 수정이며 결정 로직
무접촉. 대안을 검토했으나 전부 더 큰 접촉이다(러너의 sorts_start 가
`~/sorts.yaml` 고정, 렌더-배포가 원자적이라 밖에서 개입 지점 없음).
**해제 없이는 진행 불가 — 판단 요청.** 검증은 회귀 96행 + obs_iface
미지정 재현런(§2.1-3 항등 검증과 겸용) 제안.

### 1.4 §2.1-3 항등 검증 계획 (사전 등록, PREREG §4)

shim identity(iface=obsshim0) vs 직결(iface=ogstun) 각 1런(짧은 radio):
(a) 감지 tick 의 observed_rate·d_acc·전환 내용 동일, (b) 첫 전환 시각 차
< 1 tick, (c) during 플립 수 상대차 ≤ 15 %(경계 진동의 비결정성 — stage2
n=3 산포 근거). 완전 tick-일치는 기동 위상이 달라 정의 불가(tick 위상
양자화 — stage2 §3 규명)이므로 위 3기준으로 등록. 미달 시 정지(§5-2).

## 2. §2.2 파라미터 확정값 — `PREREG_S4.md` §1

discretize 경계 = 밴드 인접 기하평균 **{1918, 2744, 3838} kbit**(K=4+무제한;
SLO 유효 경계 ~3.6 Mbps 가 셋째 경계 구간에 보존됨), average 의 무제한 캡
= **20,000 kbit**(평균 정의에 필수 — 등록으로 고정), noise ε=0.05 시드

delay 2.0 + average + discretize. 전 factor off = identity — stage3 c6
거동(§1.4 로 검증).

## 3. shim 기동 권한 (.43) — 2안

shim 은 tc 조작이라 root 필요. .43 NOPASSWD 는 tb-radio2/tb-netem 뿐:

- **(a) 권고**: `/usr/local/sbin/tb-obshim.sh`(shim 래퍼: start <args>/stop
  — pidfile, I-15) 설치 + sudoers NOPASSWD **1줄 추가**. tb-radio2 와 동종
  표면(동일 호스트·동일 tc 도메인)이라 확대 폭 최소, 러너·드라이버가
  sudo -n 으로 arm 마다 재구성 가능(무인 배치 요건).
- (b) 대안: 배치 전 root 로 데몬 1회 기동(비번 사전 조치) — 단 arm 마다
  파라미터가 달라 **런마다 재기동이 필요**하므로 무인 배치와 충돌. 권고 (a).
