# STAGE4 사전 등록 초안 (G1 제출본, 2026-08-12 — 본 배치 전 확정 예정)

지시 §3.2 그대로 + 파라미터 확정값. 결과 데이터 없음 상태에서 등록.

## 1. 감쇠 파라미터 확정값

| factor | 값 | 근거 |
|---|---|---|
| delay 스윕 | D ∈ {0.25, 0.5, 1.0, 2.0} s (축소안 {0.25, 1.0, 2.0}) | NWDAF 초 단위 ~ RNIS 수십~수백 ms 를 걸치는 로그 간격 |
| average | 전 코호트 평균 단일값, **무제한 = 20,000 kbit 캡** 후 산술 평균 | TS 23.288 §6.9 지역 평균. 캡 = 현 밴드 최상단 20 Mbps (평균이 정의되려면 무제한의 유한 대표가 필요 — 등록으로 고정) |
| discretize | 경계 **{1918, 2744, 3838} kbit** (K=4 구간 + 무제한 상태), 보고값 = 구간 기하 중심(최하 구간 = 최저 경계 × 2/3, 최상 = 20,000 캡), **경계 교차 시에만 갱신** | 경계 = 현 밴드 집합 {1600, 2300, 3273, 4500} 의 인접 기하평균. SLO 유효 경계(search d_acc 로 S3 탈락이 갈리는 ~3.6 Mbps)가 셋째 경계(3838)와 같은 구간에 놓임 — 이산화가 SLO 관련 전이를 보존하는 최소 K |
| noise | ε = **0.05** (상대 가우시안 σ), 시드 = 런별 고정 정수(매니페스트 `noise_seed` 기록: rep1=1001, rep2=1002, rep3=1003) | RNIS 실측 노이즈 모사 (수 % 수준) |
| rnis 합성 | delay 0.15 + noise 0.05 | RNIS-like |
| nwdaf 합성 | delay 2.0 + average + discretize | NWDAF-like |

shim 폴링 20 ms — identity 전파 실측 12~19 ms, delay 실효 = D + ~60 ms
(폴링+tc 오버헤드; D 대비 ≤6 %, 전 arm 동일 가산이라 스윕 형상 불변 — 보고
시 실효 지연을 병기).

## 2. P-S4-1 ~ P-S4-6 (지시 §3.2 그대로 등록)

1. **P-S4-1 (지연 무릎)**: 위반율이 D 에 단조 증가, 무릎 존재. 무릎 위치는
   **d\* = 42.5 s(2단계)와 비교해 서술** — 지연이 반응 여유를 잠식하는 형태.
   (배경 예측: 반응 지연 ≈ 발효 + D + [0,T) 이므로 c1 위반의 burst 성분이
   D 에 비례 증가. D=2 s 에서 burst ≈ (0.256+2+0.5)/120 ≈ 창의 2.3 %.)
2. **P-S4-2 (해상도)**: average 에서 c1 열화 희석(2300 대 평균 17,050 →
   d_acc 17.1 → 2.3 ms)으로 **감지 실패 → c1 위반 급증**. 비열화 코호트도
   평균값 적용으로 오배정 가능 — 비열화 위반율 필수 병기.
3. **P-S4-3 (starved 반전)**: average 에서 starved stale **감소**(라우팅
   분화가 사라지므로). 감소했는데 위반이 늘면 = **커버리지와 해상도의
   상충** — 핵심 표.
4. **P-S4-4 (이산화)**: discretize 는 플립 **감소** 가능(양자화 =
   히스테리시스 유사). 위반율과 플립 분리 보고 — I-17 입력.
5. **P-S4-5 (합성)**: rnis ≈ ideal (주 지표 차 ≤ 0.1 %p), nwdaf 명확 열화.
6. **P-S4-6 (가산성)**: nwdaf 열화 ≟ Σ(단일 factor 효과). 초가산 = 상호작용
   보고(정지 아님).

## 3. 판정 분해 (지시 §3.3)

average 계열은 위반율 하나로 뭉치지 않는다 — arm × {**감지 실패 여부**
(교란 창 내 c1:search 이탈 결정 존재?), **커버리지**(starved tick·obs 비율),
**위반**(c1·비열화 분리)} 3분해 표 필수.

## 4. Ideal 앵커 (정지 조건 §5-3)

ideal arm 은 stage3 c6 arm 대역과 대조: 비열화 위반율 0.0139±0.0076 %
(±2σ → < 0.03 %), c1 위반 0.08~0.29 %, A1 ∈ [0.222, 0.282], d_acc 17.118.
이탈 시 정지·보고. + §2.1-3 **항등 검증**(shim on/off 결정 동일성) 기준:
(a) 감지 tick 의 observed_rate·d_acc·전환 내용 동일, (b) 첫 전환 시각 차
< 1 tick, (c) during 플립 수 상대차 ≤ 15 %(플립은 경계 진동이라 완전 결정
아님 — stage2 n=3 산포 근거). 미달 시 정지(§5-2).

## 5. 매트릭스·시드

## 6. 항등 검증 기준 정정 (회신 §2)

- **(c') 주 기준 교체**: 무교란 **pre 창**의 `decisions.csv` 가 shim
  identity 와 직결에서 **전 tick 동일** (기동 위상 오프셋 보정 후 결정 열
  비교 — ts 제외). pre 창은 클린 800 rps 에서 진동 0회(stage2·드라이런
  실측)라 결정적이므로 대역이 아닌 **일치 판정**.
- (a) 감지 tick 의 observed_rate·d_acc·전환 내용 동일, (b) 첫 전환 시각 차
  < 1 tick — 유지.
- during 플립 수는 **관측 항목 강등** (stage3 c6 σ/μ≈0.97 이라 15 % 대역은
  현상보다 정밀 — 기준 폐기). 차이가 크면 보고, 항등 실패 판정 아님.

## 7. P-S4-3 인과 분해 (회신 §3 — 결과 전 등록)

shim 은 rate 경로만 바꾸고 f_c 는 건드리지 않는다. average 에서 starved 가
줄면 두 경로를 구분해야 한다:

- 보고 필수 병기: starved tick 와 함께 **라우팅 분화 정도** — ① 트래픽이
  있는 (site,class) 칸 수, ② 코호트 목적지 이질도(서로 다른 목적지 집합을
  갖는 코호트 쌍 비율, during 창 tick 평균).
- **갈래 A (분화 소멸형)**: 분화 자체가 사라져 starved=0 → 등록 문구:
  "**해상도 소실이 관측 문제를 함께 지운다**" — 관측 지표만 보면 개선처럼
  보이는데 성능은 나빠지는 그림 (강한 서술).
- **갈래 B (커버리지형)**: 분화가 유지되는데 칸이 채워져 starved=0 →
  등록 문구: "커버리지와 해상도의 상충".
- 표에서 두 경우를 구분해 서술을 결과에 따라 선택한다(두 문구 모두 사전
  등록 — 사후 작문 아님).

## 8. 실효 지연 병기 (회신 §1.3)

전 보고에서 지연은 **명목/실효(=D+~60 ms) 병기**. P-S4-1 무릎과 §1 산출
문장("서브초")의 판정은 **실효 기준**.
