## 6. 채택의 유효 범위 (§3 지시, 런 추가 0)

같은 단위로 두 비용을 놓고 교차점을 냈다 (전부 c1 search, 발효 기준):

- **B** = 밴드 변화 **1회당** 주기 비용 = **41.7건** (T=1 s) / **0건** (T≤50 ms)
- **R** = 열화 **지속 1초당** 관측 신선도 비용 = 116.7건 / 119.0 s = **0.980건/s**
- 교차 `B = R·d` → **d\* = 42.5 s**, **f\* = 1.41 회/분**
- 본 테스트베드 = **0.50 회/분** (120 s 창에 스텝 1회) — 임계의 약 1/3

**전제 반박(중요)**: "교란 f 회/분"만으로는 교차점이 나오지 않는다. 각 교란의
지속시간이 고정이면 burst 항과 잔여 항이 **둘 다 f 에 비례**해 f 가 소거된다.
의미 있는 임계는 **밴드 변화 간격**(= 열화 지속시간당 변화 횟수)이며, 위
d\*/f\* 는 그 형태로 낸 값이다.

가정(명시): ① 스텝 교란 1회 = burst 1회(실측), ② 교란 간 독립, ③ 열화 지속
중 잔여 위반율 일정(실측 균일), ④ 모집단 c1 search·밴드 2300 kbit·부하
800 rps·SLO 45 ms 조건부, ⑤ T≤50 ms 의 burst ≈ 0(실측 0건, 6/6).

**논문 문구(§3-3 지시)**: "제어 주기 단축의 이득은 밴드 변화 빈도에 비례하고
관측 신선도에 상한이 걸린다. 본 테스트베드의 변화 빈도(0.50 회/분)에서는
T = 1 s 가 충분하며, 변화 간격이 42.5 s 보다 짧아지면(> 1.41 회/분) 재검토가
필요하다."

**논문용 한 문장(STAGE3 지시 §0.2-1)**: *본 조건의 밴드 변화 간격(120 s)은
임계(42.5 s)의 약 3배이며, 더 빠른 변동 환경에서는 주기 재검토가 필요하다.*

**O-RAN 정합 논거 조정(§3-4 지시)**: 기존의 "10 ms~1 s 범위가 목표 주기
25~50 ms 를 포함하므로 빠른 주기가 가능하다"는 서술은 **약화한다**. 실측에
맞는 서술은 — "빠른 주기는 표준상 가능하지만 **본 조건에서는 필요하지 않았고,
병목은 주기가 아니라 관측 신선도였다**". 25/50 ms 는 반응을 0.01~0.02 s 로
줄였으나 위반율을 바꾸지 못했고 진동만 3.2~3.4배로 늘렸다.
