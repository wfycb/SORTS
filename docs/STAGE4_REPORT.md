**해상도 요건은 강하게 입증됐고, 갱신 주기 요건은 비대칭으로 나왔다.**
(G2 §0.1 승인 — **헤드라인은 §3 의 갈래 A**: 관측 지표는 전부 개선처럼
보이는데 성능은 104배 악화한다.)

- **해상도 (UE 그룹 단위)**: 코호트 해상도를 지역 평균으로 뭉개면(`average`)
  열화 감지가 **0/3 완전 실패**하고 열화 코호트 위반율이 **0.132 % →
  13.78 % (104배)**. 산출 문장의 전반부는 이 수치로 선다.
- **갱신 주기 (서브초)**: **"서브초로 충분하다"는 실측**(rnis: 실효 0.21 s
  + ε=5 % ≈ ideal, Δ ≤ 0.071 %p)**이 섰다. 그러나 "서브초가 필요하다"는
  이 교란 빈도에서 위반율로는 서지 않았다** — 실효 2.06 s 지연에서도 c1
  위반율은 0.224 %(+0.09 %p, 등록 예측의 "무릎" 부재)이고 비용은 반응
  시간에 선형으로 실린다(감지 반응 1.01 → 1.06 → 2.04 s). 갱신 요건은
  **교란 빈도 조건부**다: 지연 D 는 반응 여유를 D/d\*(=42.5 s) 만큼
  잠식하므로, 밴드 변화 간격이 d\* 에 접근하는 환경에서만 서브초가
  위반율 요건이 된다(2단계 유효 범위 산출과 정합).

**확정 문구** (G2 §0.2 — 뒷항 수정 후 확정):
> "최소 노출 요건은 **UE 그룹 단위 해상도**다(평균화 시 104배 악화).
> 갱신 주기는 서브초면 충분하나 **필요조건은 아니며**, 그 필요성은 밴드
> 변화 간격이 d\*=42.5 s 에 접근하는 환경에서 발생한다."

이 수정이 §7 논증을 더 날카롭게 만든다 — TS 23.288 §6.9 가 부적합한 이유가
"느려서"가 아니라 **"지역 평균이라서"**로 특정된다. §7 표에서 **granularity
열이 결정적이고 시간 척도 열은 부차적**이라는 뜻이므로, §7 문구의 강조점을
그에 맞춰 옮긴다(§7 본문은 인수인계 문서에 있어 이 저장소 밖 — 반영은
지시자 몫으로 남긴다).

### 0.1 관측 채널별 신선도 요구 — 2단계와의 정합 (G2 §0.3)

> **관측 채널마다 신선도 요구가 다르다. 서버 지연 관측(`f_c`, `WINDOW_S`)은
> 신선도가 지배하고, 무선 관측(`rate`)은 해상도가 지배한다.**

2단계 헤드라인("병목은 제어 주기가 아니라 관측 채널의 신선도")과 이 단계의
결과("관측 지연 2 s 도 위반율에 거의 무해")는 **모순이 아니라 채널이 다른
것**이다 — 2단계의 잔여 위반 99 % 는 `f_c` 스테일에서 왔고, 이 단계에서
지연시킨 것은 `rate` 채널이다. 두 채널은 서로 무접촉이라(§4 delay 항목)
한 단계의 결론이 다른 단계를 뒤집지 않는다.

## 4. 감쇠 기전 세부

- **average**: 평균 (2300+5×20000)/6 = 17,050 kbit → d_acc 2.9 ms → 전
  사이트 slack 양수 → c1:search 가 S3 를 떠나지 않음(감지 0). 위반은 전부
  c1 열화 그 자체(라우팅 무대응)의 결과다. 비열화는 평균값이 무제한
  근처라 결정 불변 — 오배정 경로는 이 밴드 구성에선 발현하지 않았다
  (등록 시 병기 요구 이행).
- **delay**: 감지 반응이 실효 지연에 정확히 승차(1.01/1.06/2.04 s —
  D+위상). 위반율 증분은 burst 성분(≈D×c1 search rps×위반률)뿐이라 창
  120 s 대비 미미. **rate 채널 지연은 f_c 채널(무접촉)과 독립**이라
  2단계의 "잔여 위반 99 % = f_c 신선도" 구조가 그대로 유지된다.
- **discretize**: c1 poor(2300)가 구간 대표 2316 으로 보고돼 d_acc 차이
  0.1 ms 미만 — 위반율 무해. 플립 증가 경향은 유의성 미달(§2).
- **noise ε=5 %**: d_acc 17.1→17.9 ms 수준의 요동 — 결정 경계에 못 미침
  (rnis ≈ ideal 의 기전).
