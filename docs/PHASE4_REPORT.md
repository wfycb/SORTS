## 4. W 스윕 — 결정 1("표는 4.0, 권고는 2.0")의 데이터 마감

| | W=2.0 (S2/S4, n=2) | W=4.0 (W1) |
|---|---|---|
| 감지 지연(주입 지시→임계=라우팅) | **0.25 / 0.23 s** | **1.27 s** |
| c1 search 전환수(교란창) | 78/81 | 47 |
| 듀티(S3) | 33.6/34.5 % | 19.3 % |
| reserve·c2 진동 | 있음 | **소멸** |
| c1 search 위반%(during) | 2.17/2.07 | 1.35 |

- 감지는 2.0 이 ~5배 빠르다(0.24 vs 1.27 s) — "대략 2배"보다 크다.
  긴 윈도는 열화 표본이 낡은 정상 표본을 희석해 p95 가 늦게 오른다.
- 그러나 4.0 은 진동을 완화해 **위반율은 오히려 낮았다**(1.35 vs 2.1 %).
  즉 이 테스트베드의 지배 요인은 감지 속도가 아니라 진동이다.
- **권고: WINDOW_S 2.0 유지 불변**(Phase 2 값·파라미터 고정 방침).
  W 확대는 사실상 암묵적 히스테리시스로 작동하므로, 완화책 후보들과
  같은 축에서 **Phase 4 이후 작업**으로 함께 검토해야 공정하다.
  단일 런(n=1) 결과임도 유의.
