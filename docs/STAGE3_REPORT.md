## 3. P-S3-3 — starved stale 의 정직한 규명 (이번 배치의 실질 발견 ①)

- **기전**: G1 §1 의 반박("n_min 은 전 코호트 합산이라 코호트 수와 무관")은
  **전 코호트가 같은 사이트를 쓸 때만 완전하다.** 열화 유닛(c1:search)이
  플립으로 **단독** 이동한 사이트(S1)의 관측 칸은 사실상 **한 코호트의
  트래픽만으로** 채워진다 — c1:search 는 44.4 rps(c6)라 창당 ~89 < n_min
  100 → starved. c4(66.7 rps → 133/창)도 플립 듀티로 부분 체류라 미달.
  즉 **지시자의 원 우려(표 A)가 라우팅 분화 조건에서 국소적으로
  되살아난다** — 전 코호트 공유 사이트(S2/S3 정상 상태)에서는 반박대로
  무관하고, 분화 사이트에서는 코호트당 표본이 지배한다. 이는 2코호트
  현행에서도 이미 있던 현상(stage2 런의 S1/search prior 76~88 %)이며
  코호트 확장이 이를 **정량화 가능하게 드러냈다**.
- **결과 오염 없음 (3중 실측)**: ① 비열화 유닛 정책 이동 0회, ② 비열화

  유닛 자신의 플립 루프(I-6/I-13 기전)에만 관여하며, 그 유닛은 애초에
  관측 항목이다. **등록 문구대로 전 arm 을 "관측 조건 미달" 로 분류하되,
  미달이 주 지표의 판정 경로에 침투하지 않았음을 근거로 P-S3-1 결론은

## 4. P-S3-5~7 — 결합 경로의 정량화 (실질 발견 ②)

주 질문 재정의(G1 회신 §3)에 대한 답: **관측 층을 통한 코호트 간 결합은
이 부하 조건에서 측정 한계 이하다.**

- c1 열화 시 c1:search(44~133 rps)가 S2 로 이월해도 S2 는 이미 전 코호트
  트래픽 ~460 rps 를 받고 있어 f_c(S2/search) 상승이 **+0.71 ms**(c2 최대)
  에 그친다. 비열화 slack 중앙값(11~18 ms) 대비 ~5 % — slack 을 깎는
  것은 관측되나(P-S3-6 중앙값 −0.8 ms 이내) 발현 여유의 잣대에 못 미친다.
- **서술(등록대로)**: "코호트 분리는 배정 정책 수준에서 성립하며, 공유
  자원을 통한 간접 결합은 남는다. 실측 결합 크기는 f_c +0.7 ms 이하로
  비열화 slack 의 5 % 미만이었고 위반으로 발현하지 않았다. '여유가 있어
  안 보였다'가 아니라 **결합 자체가 작았다** — 열화 유닛의 이월 부하
  (≤133 rps)가 목적지 기존 부하(~460 rps)의 소수라는 총 부하 고정 조건의
  산물이며, 이월 부하가 목적지 용량 무릎에 접근하는 조건에서는 발현할
  수 있다(§4.2 유효 범위 계열 서술)."
