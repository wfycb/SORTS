# 분포표 (DISTRIBUTIONS.md) — 평균 대신 분포

STAGE6 S6-3. 2026-08-13. **런 0**(기존 원자료 재분석).
생성: `python3 analysis/stage6/distributions.py` → `analysis/stage6/distributions.json`.
지연 분위수는 **해당 창의 요청 단위 `corrected_ms`**(판정 산식과 동일 모집단),
위반율은 `t2_policy_repeat.one_run` 정의(both 창 총 위반율).

> **왜 이 문서가 필요한가**: 평균 ± 표준편차만 적으면 (a) n=2~3 에서 σ 가 거의
> 의미 없고, (b) **산포가 평균만 한 지표**(플립)를 평균으로 대표하게 되며,
> (c) 위반율의 차이가 **꼬리에 있다는 사실**이 가려진다. 본문에 쓸 때는
> 여기 값을 그대로 옮기고, 평균만 쓰는 것은 금지한다.

| arm | n | **런별 위반 %** | 평균 | corrected p50 / p90 / p95 / p99 [ms] |

읽는 법: **각 층이 꼬리를 자른다.** p50 은 89.6 → 28.1 ms 로 3.2배 줄지만
p99 는 284.2 → 47.9 ms 로 5.9배 준다. SLO(search 45 ms) 기준으로 보면 마지막
arm 에서 **p95 45.3 ≈ SLO**, p99 47.9 로 경계에 붙는다 — 위반율 6.5 %가 그것이다.
`+soft assignment` arm 의 런별 값(30.1 / 30.5 / **23.6**)은 **σ 를 쓰지 말아야
하는 예**다(세 번째 런만 6.5 %p 낮다).

## 3. 제어 주기 (stage2, 800 rps, n=3/arm)

런별 값 — `during 위반%(전체)` / **(c1 search, 판정 모집단)**:

| T | 런별 위반%(c1 search) | 평균 ± σ | 반응 p50 [s] | burst 위반 | 전환(during) |
|---|---|---|---|---|---|
| **1 s** | **0.812 · 0.650 · 0.662** | 0.708 ± 0.090 | 0.954 | 35 · 36 · 54 | 67 · 67 · 72 |
| 50 ms | **0.714 · 0.689 · 0.767** | 0.723 ± 0.040 | 0.003~0.031 | 0 · 0 · 0 | 204 · 242 · 215 |
| 25 ms | **0.650 · 0.780 · 0.689** | 0.706 ± 0.067 | 0.012~0.014 | 0 · 0 · 0 | 221 · 255 · 221 |

읽는 법: 세 arm 의 **런별 값 범위가 서로 완전히 겹친다**(0.650~0.812 /
0.689~0.767 / 0.650~0.780). 평균 최대차 0.017 %p 는 이 겹침의 요약일 뿐이며,
"주기를 줄여도 위반율이 안 준다"는 결론은 **평균이 아니라 이 겹침**이 근거다.
반대로 **전환 수는 겹치지 않는다**(67~72 vs 204~255) — 주기 단축의 실제 효과는
위반율이 아니라 전환 빈도에 있다.

## 4. 산포가 큰 지표 — **평균 금지** (stage4 플립)

`c1s_switches_during`(c1 search 결정 전환 수), arm 별 **런별 값**:

| arm | 런별 플립 | 범위 | c1 위반 % (런별) |
|---|---|---|---|
| ideal | **40 · 21 · 44** | 21~44 | 0.123 · 0.091 · 0.182 |
| rnis | **53 · 69 · 54** | 53~69 | 0.169 · 0.234 · 0.208 |
| discretize | **74 · 72 · 52** | 52~74 | 0.201 · 0.221 · 0.149 |
| delay 0.25 s | 68 · 38 | 38~68 | 0.188 · 0.169 |
| delay 1.0 s | 76 · 42 | 42~76 | 0.195 · 0.130 |
| delay 2.0 s | 56 · 73 | 56~73 | 0.130 · 0.318 |
| **average** | **0 · 0 · 0** | 0 | 14.487 · 12.717 · 14.149 |
| **nwdaf** | **0 · 0 · 0** | 0 | 14.659 · 16.027 · 15.208 |

읽는 법:

- **ideal 의 21~44 는 arm 간 차이(53~74)와 겹친다.** 그래서 STAGE4 의
  P-S4-4(discretize 가 플립을 줄인다)는 **유의성 미달로 기각**됐고, 보고서도
  "감소 아님"으로 적었다. 플립을 **평균 ± σ 로 요약하면 (35.0 ± 34.0 류)
  없는 차이를 만들어낸다** — 본문에서는 반드시 **범위 또는 런별 값**으로 쓴다.
- 반면 **`average`·`nwdaf` 의 0 은 산포가 아니라 구조**다: 해상도가 사라져
  결정 자체가 갈리지 않는다(= 관측 지표는 좋아 보이는데 위반율은 104배).
  이 두 arm 만은 "0"이라고 단정해도 된다.
- 관련 규율: I-17(플립 시간척도 하한), `analysis/method_cases.md` B-4
  ("등록 전 산포 확인").

## 5. 본문 반영 규칙

1. 평균만 쓰지 않는다. **n ≤ 3 이면 런별 값을 그대로 병기**한다.
2. 위반율을 인용할 때 **p95/p99 를 함께** 적는다 — 차이가 꼬리에 있다.
3. `corrected` 를 인용할 때 포화 구간이면 **`service` 를 반드시 병기**한다(I-19).
4. 플립·전환 수는 **범위**로 쓴다(평균 금지).
